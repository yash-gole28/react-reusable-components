# React Component Lab

A React project showcasing reusable UI components, custom hooks, and frontend performance optimization techniques built with React, TypeScript, and Vite.

## Features

- **Infinite Scroll & Virtualization** – Efficiently render large lists.
- **Drag and Drop** – Reusable drag-and-drop list components.
- **Dropdown Components** – Reusable dropdown interactions.
- **Custom Hooks** – Reusable logic for debouncing and other operations.
- **Portal Management** – Render UI elements outside the main DOM hierarchy.
- **Smart Image Handling** – Image loading and error handling.
- **Scroll Animations** – Smooth animations using Framer Motion.
- **Rendering Optimization** – Explore techniques for improving React rendering performance.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- TanStack React Query
- TanStack Virtual
- Framer Motion

## AI-Assisted Development

AI tools are used as part of the development workflow to help with component design, implementation approaches, debugging, and code improvements.

The focus is on using AI effectively to explore solutions, understand implementation details, review generated code, and integrate suitable solutions into the project.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yash-gole28/react-reusable-components.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-reusable-components
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
